# Productos Fitness

Página web de una tienda ficticia de productos fitness, hecha con HTML, CSS y JavaScript puro.

🔗 **Ver en vivo:** [enlace de tu GitHub Pages]

![Captura de la página](img/captura.png)

## Características

- Portada con imagen a pantalla completa que se desvanece al hacer scroll
- Catálogo de productos con filtro por categoría (Pesas, Cardio, Accesorios)
- Diseño responsive (celular, tablet y computador)
- Navegación con scroll suave entre secciones
- Buenas prácticas de accesibilidad: HTML semántico, textos alternativos y foco visible

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, variables CSS)
- JavaScript (manipulación del DOM, eventos)
